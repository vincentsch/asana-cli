# asana update

Update asana-cli to the latest version

## Usage

```
asana update
```

## Examples

```
asana update --check
asana update --check --json
asana update
```

## Flags

- `--check` Check for an update without installing it

## Output modes

human, json

## Changes state

This command changes state and honors `--dry-run`.
